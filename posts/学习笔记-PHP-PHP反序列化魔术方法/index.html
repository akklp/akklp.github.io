学习笔记-PHP-PHP反序列化魔术方法

一、 魔术方法简介

1. 什么是魔术方法？

魔术方法（Magic Methods）是PHP中预定义好的一些方法，它们在特定的情况下会被自动触发执行。

2. 为什么在反序列化漏洞中要学习魔术方法？

在PHP的反序列化漏洞（利用 unserialize() 函数）中，攻击者通常通过控制传入的序列化字符串来控制对象的值。而魔术方法会在反序列化的过程或对象后续的生命周期中自动调用，这就为攻击者提供了一个触发恶意代码执行的“跳板”（构成POP链的关键）。

3. 学习魔术方法的四个问题

当学习一个魔术方法时，必须弄清楚以下四个问题（其中最关键的是触发时机）：

  1. 触发时机：这个方法在什么操作下会被自动调用？（必须掌握）
  2. 功能：这个方法本来的设计用途是什么？
  3. 参数：这个方法是否接收参数？接收什么参数？
  4. 返回值：这个方法执行后返回什么值？

二、 常用魔术方法详解

1. 对象的创建与销毁

__construct() （构造函数）

  • 触发时机：在实例化一个对象（例如 new User()）的时候，首先会去自动执行。
  • 功能：提前清理或初始化不需要的内容/所需的资源。
  • 参数：非必要。
  • 返回值：无。
  • 核心考点：在利用反序列化漏洞时，unserialize() 过程并不会触发 __construct()。只有正常的实例化对象才会触发。

__destruct() （析构函数）

  • 触发时机：在对象的所有引用被删除，或者当对象被显式销毁时执行。（例如代码执行完毕，反序列化生成的对象生命周期结束时）。
  • 功能：通常用于清理对象、关闭资源连接等。
  • 核心考点：反序列化得到的对象，在用完后会被销毁，此时一定会触发 __destruct()。它常常是反序列化漏洞利用链（POP链）的入口。

2. 序列化与反序列化相关

__sleep()

  • 触发时机：在对对象进行序列化 serialize() 之前会被自动调用。
  • 功能：对象被序列化之前触发，返回需要被序列化存储的成员属性名，可以用来删除不需要序列化的属性。
  • 返回值：返回一个数组，包含需要被序列化的变量名称（return array('username', 'nickname');）。如果未返回任何内容，则 NULL 被序列化。

__wakeup()

  • 触发时机：在对对象进行反序列化 unserialize() 之前会被自动调用。
  • 功能：预先准备对象需要的资源，常用于反序列化操作中重新建立数据库连接或执行其他初始化操作，或者对反序列化进来的变量进行过滤/重新赋值。

3. 对象转换与调用

__toString()

  • 触发时机：把对象被当成字符串调用（例如使用 echo $obj，进行字符串拼接等）时触发。
  • 注意：使用 print_r() 或 var_dump() 打印对象不会触发，只有将其强制视为字符串时才会触发。

__invoke()

  • 触发时机：把对象当成函数调用时触发（例如 $obj = new User(); $obj();）。

4. 错误调用 / 属性及方法重载机制

这一组魔术方法主要用于处理调用了不存在或不可访问（如私有属性/方法的情况。

__call($arg1, $arg2)

  • 触发时机：调用一个不存在的方法时触发。
  • 参数：传入两个参数。$arg1 是不存在的方法的名称，$arg2 是传给该方法的参数数组。

__callStatic($arg1, $arg2)

  • 触发时机：静态调用一个不存在的方法时触发（例如 User::callxxx()）。
  • 参数：与 __call 类似，传入方法名和参数数组。

__get($arg1)

  • 触发时机：调用的成员属性不存在（或不可访问）时触发。
  • 参数：$arg1 为不存在的成员属性的名称。

__set($arg1, $arg2)

  • 触发时机：给不存在的成员属性赋值时触发。
  • 参数：$arg1 为不存在的成员属性名称，$arg2 为要赋予的值。

__isset($arg1)

  • 触发时机：对不可访问属性使用 isset() 或 empty() 时被调用。
  • 参数：$arg1 为不存在的成员属性名称。

__unset($arg1)

  • 触发时机：对不可访问属性使用 unset() 时被调用。
  • 参数：$arg1 为不存在的成员属性名称。

5. 对象克隆

__clone()

  • 触发时机：当使用 clone 关键字拷贝完成一个对象后，新对象会自动调用定义的魔术方法 __clone()。

三、 魔术方法触发时机速查表

魔术方法 触发时机摘要
__construct() 使用 new 实例化对象时触发
__destruct() 对象被销毁时触发（反序列化POP链常用入口）
__sleep() 执行 serialize() 之前触发
__wakeup() 执行 unserialize() 之前触发
__toString() 对象被当作字符串使用时触发（如 echo）
__invoke() 对象被当作函数调用时触发（如 $obj()）
__call() 调用对象中不存在的普通方法时触发
__callStatic() 调用对象中不存在的静态方法时触发
__get() 读取对象中不存在的属性时触发
__set() 给对象中不存在的属性赋值时触发
__isset() 对对象中不存在的属性使用 isset()/empty() 时触发
__unset() 对对象中不存在的属性使用 unset() 时触发
__clone() 使用 clone 关键字复制对象时触发
