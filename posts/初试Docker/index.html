1.2 Docker镜像管理命令

docker pull - 下载镜像

  • 从Docker仓库下载镜像到本地。
  • 镜像构成: 一个完整的镜像名称包含四部分：[registry_address/] [namespace/] image_name [:tag]

具体命令含义介绍

  • registry_address: Docker仓库的注册表地址。 docker.io表示Docker Hub官方仓库，可省略。

  • namespace: 命名空间，通常是作者或组织名称。library是Docker官方仓库的命名空间，可省略。

  • image_name: 镜像的名称。

  • tag: 镜像的标签名，通常表示版本号。latest表示最新版本，可省略。

  • 示例:

    • docker pull nginx: 从Docker Hub官方仓库下载最新版Nginx镜像。

    • docker pull n8n/n8n: 从N8n的私有仓库下载N8n镜像。

ps： 很多人在拉取镜像的时候会碰到网络问题，一般的解决方法是配置镜像站，我闲麻烦就直接开全局魔法解决了。

  • docker images - 列出本地镜像

    • 功能: 列出所有已下载到本地的Docker镜像。

  • docker rmi - 删除镜像

    • 功能: 删除本地的Docker镜像
    • 通过设置参数可以删除指定镜像名称或者ID

1.3 Docker镜像管理命令

  • docker run - 创建并运行容器

    • 功能: 使用指定的镜像创建并运行一个容器。
    • PS： 若本地不存在指定的镜像，则会优先拉取镜像，再创建并运行容器

  • docker run参数解析

    1. -d(后台运行 / Detached Mode)
      • 让容器在后台执行，不阻塞当前终端窗口。
      • 控制台只打印容器ID，容器日志不会直接输出到终端。
      • 示例: docker run -d nginx
    2. -p (端口映射 / Port Mapping)
      • 由于Docker容器运行在独立的虚拟网络环境中，默认无法直接从宿主机访问容器内部网络。
      • 运用这个我们可以将宿主机的端口映射到容器内部的端口。
      • 语法: -p <宿主机端口>:<容器内部端口>
      • 示例: docker run -d -p 8080:80 nginx
    3. -v(挂载卷 / Volume Mounting)
      • 由于docker容器一旦被删除，数据就全没了，因此我们需要-v来使数据持久化
      • 功能: 将宿主机的文件目录与容器内的文件目录进行绑定。
      • 有两种挂载方式：
        1. 绑定挂载 (Bind Mount)：直接将宿主机目录路径写入命令。
          • 语法: -v <宿主机目录路径>:<容器内部目录路径>。
        2. 命名卷挂载 (Named Volume): 让Docker自动创建一个存储空间，并为其命名。
        • 创建命名卷: docker volume create <卷名称>。
        • 使用命名卷: -v <卷名称>:<容器内部目录路径>。
    4. -e (Environment Variables / 环境变量)
      • 向容器内部传递环境变量
    5. --name (自定义容器名称)
    6. -it (Interactive & TTY / 交互式终端)
      • 让控制台进入容器内部，获得一个交互式的命令行环境。
      • 语法: docker run -it <镜像名称> /bin/bash
    7. --rm (运行结束后自动删除)
    8. --restart (重启策略)
      • 常用策略：
      • always: 只要容器停止，就会立即重启。
      • unless-stopped: 除非手动停止容器，否则都会尝试重启。可自动重启因意外停止的容器，而手动停止的容器不会再重启。

  • docker ps: 查看正在运行的容器。

    • 输出信息包括：Container ID（容器唯一ID）、Image（基于哪个镜像创建）、Names（容器名称）。
    • docker ps -a: 查看所有容器

Dockerfile 指令

核心构建指令

指令 说明 示例
FROM 指定基础镜像，必须是第一条指令 FROM ubuntu:20.04
WORKDIR 设置工作目录，后续指令在此目录执行 WORKDIR /app
COPY 复制文件/目录到镜像中 COPY . /app
ADD 复制文件到镜像中，支持URL和自动解压 ADD app.tar.gz /app
RUN 在构建时执行命令 RUN apt-get update
CMD 容器启动时的默认命令 CMD ["python", "app.py"]
ENTRYPOINT 容器启动时的入口点，不会被覆盖 ENTRYPOINT ["./start.sh"]

网络和存储指令

指令 说明 示例
EXPOSE 声明容器监听的端口 EXPOSE 8080
VOLUME 创建挂载点 VOLUME ["/data"]

环境配置指令

指令 说明 示例
ENV 设置环境变量 ENV NODE_ENV=production
ARG 定义构建时参数 ARG VERSION=1.0

元数据和高级指令

指令 说明 示例
LABEL 添加镜像元数据 LABEL version="1.0"
ONBUILD 当镜像作为基础镜像时触发的指令 ONBUILD COPY . /app

健康检查和Shell指令

指令 说明 示例
HEALTHCHECK 定义容器健康检查 HEALTHCHECK CMD curl -f http://localhost/
SHELL 指定默认shell SHELL ["/bin/bash", "-c"]
