SQL注入 - UpdateXml报错注入笔记

一、 updatexml 函数简介

updatexml(XML_document, XPath_string, new_value) 函数包含三个参数，常用于更新 XML 文档的内容：

  • 第一个参数 (XML_document): string 格式，为 XML 文档对象的名称，例如 doc。在注入时可随意填入一个值，如 1。
  • 第二个参数 (XPath_string): XPath 格式的字符串路径。这是触发报错注入的关键参数。
  • 第三个参数 (new_value): string 格式，表示要替换成的新值。在注入时也可随意填入一个值，如 3。

二、 报错注入原理

updatexml() 的报错原理与 extractvalue() 非常相似。当我们向第二个参数（XPath_string）传入不符合 XPath 语法的格式（例如包含特殊字符 ~）时，数据库会产生报错，并且会在报错信息中将我们传入的非法路径内容连同 SQL 语句的执行结果一起显示出来。

限制：无论是 extractvalue() 还是 updatexml()，其报错信息回显的长度最大只能是 32 个字符。

四、 总结回顾

  1. 最先需要做的：首先要判断是字符型还是数字型注入；如果是字符型，必须先准确判断出闭合方式（如 '、"、')、") 等）。
  2. 关键函数介绍：
  • database(): 查询当前数据库名。
  • group_concat(): 把查询到的多行结果合并为一行显示。
  • concat(): 合并拼接字符串。
  • substring(str, pos, len): 从字符串 str 的 pos 位置开始截取 len 个字符。
  1. 拓展:
  • 如果不使用 group_concat() 合并数据，而是让查询返回多行结果，可以直接使用 limit 0,1 取第一行，limit 1,1 取第二行… 这样逐行输出也是绕过长度限制的一种常用有效方法。
