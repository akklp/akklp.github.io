学习笔记-PHP-反序列化基础知识

一、 类与对象基础

1. 类的结构与内容

  • 基本组成：类由类名、成员变量（属性）和成员函数（方法）三部分组成。
  • 定义示例：
  • $this 的作用：在类的内部，使用 $this 来调用当前类的成员属性和成员方法。

2. 实例化和赋值

  • 实例化：类只是一种抽象的结构，使用 new 关键字可以将其实例化为具体的对象。
  • 赋值与调用：实例化后，可以对对象的属性进行赋值，或调用其方法。
  • 打印对象：如果使用 print_r() 或 var_dump() 打印对象，只会打印出对象的成员变量（属性），不会显示其成员函数。

3. 类的修饰符

类的成员可以有不同的访问权限修饰符，它们决定了属性或方法的调用范围：

  • public（公共的）：默认权限。在类的内部、子类中以及类的外部都可以使用，不受限制。
  • protected（受保护的）：只能在当前类的内部和其子类中使用，类的外部无法访问。
  • private（私有的）：只能在当前类的内部使用，类的外部或子类中都无法使用。

二、 序列化基础知识

1. 序列化的作用

  • 序列化 (serialize())：将对象的状态信息（如属性）或数组转换为可以存储或传输的字符串形式的过程。
  • 便于在网络中传输，或将其保存到文件、数据库中。

2. 不同数据类型的序列化格式

各类数据经过 serialize() 函数处理后，其格式缩写及表现形式如下：

  • 空字符 (null)：N;
  • 整型 (integer)：i:666;
  • 浮点型 (float)：d:66.6;
  • 布尔型 (boolean)：true 会序列化为 b:1;，false 会序列化为 b:0;。
  • 字符串 (string)：s:6:"benben";（格式为 s:长度:"内容";）
  • 数组 (array)：a:3:{i:0;s:6:"benben";i:1;s:8:"dazhuang";i:2;s:6:"laoliu";}
    • 格式为 a:元素个数:{键1;值1;键2;值2;...}。

3. 对象的序列化

  • 基本格式：O:4:"test":1:{s:3:"pub";s:6:"benben";}
    • O 代表 Object（对象）。
    • 4 是类名长度，"test" 是类名。
    • 1 代表该对象中包含的属性个数。
    • {...} 内部是成员属性的键值对序列化结果。
  • 重要特性：
    1. 不能序列化“类”本身，只能对实例化后的对象进行序列化。
    2. 对象的序列化只包含其成员变量（属性），不包含成员函数（方法）。

4. 修饰符对对象序列化的影响

由于访问修饰符的不同，对象在序列化时，属性的名称会有特殊的格式：

  • public（公有）：按照正常属性名序列化。如属性 pub 序列化为 s:3:"pub"。
  • protected（受保护）：会在属性名前加上 \x00*\x00（URL编码为 %00*%00）。
    • 示例：名为 pub 的受保护属性，变量名长度为 1+1+1+3 = 6，序列化格式为 s:6:"\x00*\x00pub"。
  • private（私有）：会在属性名前加上 \x00类名\x00（URL编码为 %00类名%00）。
    • 示例：在 test 类中名为 pub 的私有属性，变量名长度为 1+4+1+3 = 9，序列化格式为 s:9:"\x00test\x00pub"。(即：s:9:"%00test%00pub")

(注：在构造反序列化Payload测试时，遇到私有和受保护属性常常需要结合 urldecode() 或在 BurpSuite 中将其直接 URL 编码处理，以防空字符 \x00 导致解析截断。)

三、 反序列化的特性

  • 反序列化 (unserialize())：将序列化后的字符串还原回具体的实例化对象。
  • 值由外部输入决定：反序列化生成对象里的属性值，完全是由反序列化传入的字符串里的值来提供的，与原类中预定义的默认值无关。（这也是反序列化漏洞能够篡改程序执行逻辑的核心原因）。
  • 不自动触发普通方法：反序列化过程本身不会去自动触发类中的普通成员方法，如果需要执行，需要程序原本的代码中有明确的调用该方法的逻辑（或者依赖后续会讲到的特定“魔术方法”）。
